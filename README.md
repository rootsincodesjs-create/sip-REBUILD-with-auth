# SIP: Women in STEM Interactive Platform

This project is an interactive digital platform developed as my Senior Integrated Project (SIP). It centers the stories, histories, and lived experiences of women of color in STEM through interactive design, storytelling, and community-oriented features.

The goal of this project is to explore how creative technology, design, and code can be used to challenge exclusionary narratives in STEM and create spaces for visibility, connection, and shared memory.

---

## Project Features

- **Interactive Map**  
  Users can submit their own stories, which are visually represented as map pins tied to geographic locations.

- **Timeline of Historical Figures**  
  A curated timeline highlighting women of color who have contributed to STEM fields across history.

- **Community Chat Space**  
  A real-time chat feature designed to foster connection, discussion, and mutual support.

- **Authentication & Profiles**  
  Users can create accounts, log in, and participate in community features.

---

## Technologies Used

- HTML, CSS, JavaScript  
- Firebase (Authentication, Firestore)  
- Figma (UI/UX design and prototyping)

---

## Design & Development Process

The platform was first designed and prototyped in Figma, with an emphasis on accessibility, storytelling, and visual identity. Features were then implemented incrementally using web technologies and Firebase, allowing for real-time interaction and dynamic content.

This project is actively evolving as features are refined and expanded.
